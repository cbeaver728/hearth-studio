Hearth Studio - Local Browser Edition

1. Extract the entire ZIP to a folder.
2. Double-click "Start Hearth Studio.cmd".
3. Your browser opens Hearth Studio at http://127.0.0.1:4173.

Requires Node.js 22 or newer. No npm install or internet connection is needed.
Keep the command window open while using the app. Close it when finished.
The server only listens on your own computer.

Projects autosave in this browser. Use Export project for portable .hearth backups.
Keep using the same browser and address to access your saved projects.
The browser edition exports project files using Downloads rather than a native Save dialog.

Source: https://github.com/cbeaver728/hearth-studio
